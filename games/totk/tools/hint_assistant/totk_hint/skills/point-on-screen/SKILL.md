---
name: point-on-screen
description: 玩家点了“指给我看”、要在画面上圈出东西时：先确认要圈什么，再用 mark_screen 圈在目标本身上
---
1. 先想清楚要圈的是什么：
   - 解谜时只圈攻略里提到的机关或位置（先用 guide 查）；
   - 找东西时，只圈玩家问的那样东西。
2. 只圈画面里确实认得出的东西。光线、反光、特效、远处的模糊物体容易认错，认不准就不圈，用文字说明在哪个方向。
3. 圈的中心落在目标本身上，不要落在林克身上。目标被林克挡住或在画面外时，用箭头从林克指向它所在的方向。
4. 最多圈 3 处，每处标签 2–8 个字，用游戏原名；回答里用“圈出的……”指代。
5. runtime_state 里附近物体的方位（正前方、左侧……）可以帮着确认画面里的东西是哪一个。
